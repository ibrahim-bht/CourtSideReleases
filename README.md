# CourtSide

CourtSide is a sports app for Mac and Windows. It covers live scores, game pages, standings and fantasy for the NFL, NBA and soccer.

This repository only hosts the downloads. The source code is private.

## Download

Get the latest version from [Releases](https://github.com/ibrahim-bht/CourtSideReleases/releases/latest).

- **Mac:** download `CourtSide.dmg`, open it and drag CourtSide into Applications. The app isn't notarized yet. The first time you open it, right-click it and choose **Open**, or go to System Settings › Privacy & Security › **Open Anyway**.
- **Windows:** download `CourtSide-<version>-setup-x64.exe` to install it, or the `portable` file to run it without installing. If SmartScreen warns you, choose **More info › Run anyway**.
